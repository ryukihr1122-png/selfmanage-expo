# キャラクターコンセプト — SelfManage

ChatGPTでの画像生成用コンセプトシート。
6キャラ × 5段階 = 30画像。

---

## 共通ルール

- **画風**: 水彩タッチ + ゲーム風（ドラクエ・ポケモンの中間くらい）
- **背景**: 透明（PNG）
- **サイズ**: 512x512px
- **トーン**: 温かみのある、親しみやすいデザイン
- **タマゴ段階**: すべて同じ基本形で色違い（ジャンルのテーマカラー）

## 成長段階

| Stage | 名前 | Lv条件 | イメージ |
|-------|------|--------|---------|
| 0 | タマゴ | Lv.0 | テーマカラーの模様入りタマゴ |
| 1 | 幼体 | Lv.1 | タマゴから孵化した小さな生き物 |
| 2 | 成長体 | Lv.10 | 少し大きくなり特徴が出てくる |
| 3 | 成体 | Lv.25 | 完全に成長した姿 |
| 4 | 覚醒体 | Lv.50 | 輝くオーラ、最終形態 |

## ChatGPT用プロンプトテンプレート

```
以下のキャラクターの[Stage X: ○○]段階の画像を生成してください。

キャラクター名: [名前]
ジャンル: [ジャンル]
テーマカラー: [カラー]
段階: [Stage X - 段階名]
描写: [描写テキスト]

スタイル要件:
- 水彩タッチ + ゲーム風キャラクターデザイン
- 背景は白（後で透過処理）
- 512x512px正方形
- 温かみのある親しみやすいデザイン
- RPGゲームのコンパニオンキャラクターとして
- 全身が収まるように（頭身は2〜3頭身でデフォルメ）
```

## ファイル命名規則

```
assets/characters/{character_id}_stage{N}.png

例:
assets/characters/fitness_flame_stage0.png  (タマゴ)
assets/characters/fitness_flame_stage1.png  (幼体)
assets/characters/fitness_flame_stage2.png  (成長体)
assets/characters/fitness_flame_stage3.png  (成体)
assets/characters/fitness_flame_stage4.png  (覚醒体)
```
